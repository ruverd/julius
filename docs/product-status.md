# Julius product status

Status as of September 21, 2026. This matrix audits the active Python/Rust product against the [product specification](specification.md) and [completion plan](plans/2026-09-21-product-completion.md). “Live” means a bounded operation was observed against an actual client or service; it does not imply general compatibility, provider billing accuracy, task quality, or realized savings. The active architecture follows the [approved migration](plans/2026-09-21-stack-migration.md).

The current product is a locally validated foundation with limited live integration evidence. xAI/Grok compatibility is fixture-only; Jev remains shadow-only. Candidate compression is not a measured sent-request input reduction. Output token usage is recorded where available, but output savings require a comparable baseline and are not established. The one live Claude pair cost more with the safe hook. The direct input-reduction target and financial savings are hypotheses until sent-request measurements and comparable baselines exist. The [validation record](validation.md) is the authority for the exact local checks and their limits.
