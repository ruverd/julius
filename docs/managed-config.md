# Managed local configuration

`julius.managed_config.ManagedConfig` is a small, opt-in file manager. A caller supplies an allowed configuration directory, a separate private state directory, a target path under the allowed directory, and the complete desired file bytes. It does not discover or edit user configuration on its own.

Call `plan(target, desired_bytes)` first. The returned `ConfigPlan` contains a unified text diff, the SHA-256 hash of the current file (`None` if absent), the desired hash, and the desired bytes. Planning reads the target and does not write it. Review the diff before calling `apply(plan)` in response to an explicit user action. Apply checks the original hash again and rejects a changed target. Repeating the same apply is a no-op.

The first apply writes a private backup and manifest under the state directory, checks the target again, then atomically replaces it. The backup holds the exact prior bytes; the manifest records its hash, mode, and the managed hash. `remove(target)` restores the original bytes and mode (or removes a file Julius created), but only while the target still matches the managed hash. Repeating remove is a no-op. Detected external edits are preserved. Resolve drift manually before retrying. An external writer that changes the target in the narrow interval after the final check can still race with replacement; do not apply or remove while the client is editing that file.

Paths outside the allowed directory, parent traversal, symlinks, non-regular files, and hard-linked files are rejected. Keep the state directory private and separate from the configuration directory. The diff is a text preview and may expose credentials present in the configuration; review it locally and do not export it by default. For non-UTF-8 bytes, undecodable characters appear as replacement characters, while apply and restore retain exact bytes. The manager does not merge configuration formats or guarantee recovery after a machine crash between its separate backup, manifest, and target writes.
