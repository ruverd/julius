# Offline input-cost attribution

`julius.cost_attribution.attribute_input_cost` decomposes one comparable sent request in a fixed order: baseline text at the baseline model, compressed text at the baseline model, then the same compressed text at the actual model. The first cost difference is the compression effect; the second is the routing effect. Their signed sum equals the total modeled effect. A negative value means the step increased modeled input cost.

The caller supplies three pinned counts (`before_baseline`, `after_baseline`, `after_actual`), each with its text SHA-256 digest, actual model ID, tokenizer ID, and token count. The two after-text digests must match. The baseline before and after counts must use the same tokenizer. Counts from different tokenizers are never subtracted from one another as token savings. The caller also supplies the request time, two explicit USD input-price snapshots with source and source date, actual model IDs, the cache regime, and `sent_acknowledged: true`. Prices must be effective at the request time. The function performs no network call or ledger write.

Only an uncached input regime is modeled. Missing counts, model IDs, tokenizers, text hashes, dated prices, sent acknowledgement, or a supported cache regime return `status: unavailable` with all monetary fields null. Different after-text digests are unavailable. Contradictory pinned model or tokenizer identities raise an error. Returned costs use `Decimal`; stage records name their model, tokenizer, text digest, price snapshot, and evidence. The scope is `one_sent_request_modeled_uncached_input`. It excludes output, cache charges, auxiliary calls, retries, task coverage, quality effects, provider billing, and invoice savings.

For example, at $10 per million input tokens, 10,000 baseline tokens cost $0.10 and 4,000 compressed tokens cost $0.04, giving $0.06 compression savings. If the compressed text counts as 4,500 tokens on a second tokenizer priced at $5 per million, its modeled input cost is $0.0225 and the routing effect is $0.0175. Total modeled input savings are $0.0775. The 4,000 and 4,500 token counts are never compared as a token reduction.
