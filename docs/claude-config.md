# Planning Claude Code project configuration

`julius.claude_config.plan_claude_project_config` accepts the existing bytes of project `.claude/settings.json` and `.mcp.json` (or `None` for a missing file), a reviewed complete hook shell command, and an MCP executable plus argument list. It returns complete desired bytes for both files. It never reads or writes files, launches Claude, or installs anything. Review both resulting files before passing them to `ManagedConfig.plan` and `ManagedConfig.apply`. Use project-local paths and keep the recovery server and hook on the same project and artifact store.

The planner appends one `PostToolUse` matcher for `Bash` to `.claude/settings.json` and one `julius-recovery` stdio server to `.mcp.json`. Existing settings, permissions, hooks, and other MCP servers remain. It refuses an occupied Julius server name, a preexisting Julius hook command, malformed JSON, and unexpected hook/MCP container types. `unmerge_claude_project_config` removes only the exact entries from the plan and preserves unrelated later changes; it refuses a missing or changed Julius entry. The functions serialize JSON, so formatting and key spacing can change even when values do not.

Persistent project `.mcp.json` entries are shared configuration. Claude Code [prompts for approval in interactive sessions but loads project servers without that prompt in noninteractive and Agent SDK sessions](https://code.claude.com/docs/en/mcp#project-scope). Treat the generated configuration as executable project code, review it before applying, and prefer a temporary launcher configuration when persistence is unnecessary. The planner cannot prove that the recovery server is registered and usable; the hook's `--recovery-available` flag remains an operator attestation. Fixture tests do not establish live Claude compatibility.

Wire references: [Claude Code hooks](https://code.claude.com/docs/en/hooks), [project MCP configuration](https://code.claude.com/docs/en/mcp), and [settings files](https://code.claude.com/docs/en/settings).
