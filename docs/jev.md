# Jev shadow decision boundary

Status: experimental direct TypeSafe HTTP gateway. One earlier live Choice request with synthetic state succeeded on September 21, 2026, returning `jev-1.13.0`, 373 input tokens, 31 output tokens, `compress`, and confidence `0.77`. Dollar cost was unavailable because no price was configured. A later [pinned five-call shadow pilot](live-jev-shadow.md) matched three of five frozen synthetic policy labels with price-modeled auxiliary cost. These are protocol and narrow synthetic decision observations, not a target-task quality benchmark or active-decision validation.

`julius.jev.shadow_decide` accepts an injected `JevGateway`. Normal Julius installation does not need TypeSafe credentials, a model, or network access. The explicit `julius jev shadow` CLI command and `Julius.evaluate_jev_shadow` SDK method invoke this module when called; SDK records a decision and any auxiliary usage in the local ledger. `TypeSafeGateway` uses one direct HTTPS POST to `https://api.typesafe.ai/v1/systemone`, Bearer authentication, `jev-latest` by default, and a Choice question. A caller can pin a versioned `model_id` for evaluation. Its transport disables environment proxies and redirects, performs no retries, and caps response at 64 KiB. Python socket timeout bounds network I/O; caller's deadline also rejects responses that arrive late. An injected transport supports fixture tests.

The module uses only a Choice-shaped response for three eligible actions: `keep`, `retrieve`, and `compress`. The official TypeSafe documentation also defines Score and Noul, but neither is needed for this narrow shadow choice. The gateway maps TypeSafe's `response.answers[question_id].choice` and `.confidence` into `JevAnswer`. The earlier smoke request and five-call pilot establish compatibility for the observed `jev-1.13.0` shape, not every model or future release.

Only six metadata fields can reach a gateway. `input_tokens` and `estimated_reduction_tokens` must be exact integers from 0 through 1,000,000,000; booleans do not count as integers. `artifact_recoverable`, `has_protected_content`, `model_local`, and `repetitive_content` must be exact booleans. Other keys are dropped. An invalid value under an allowed key produces `invalid_state` before any gateway call. Direct `TypeSafeGateway.choose` calls raise `ValueError` for the same invalid state. Raw prompts, paths, project identifiers, and secrets are excluded; callers should still pass only authorized state.

The ordinary `julius jev shadow` command refuses dispatch unless it has `--model` set to a versioned Jev ID, `--price-source` and ISO `--price-date`, both `--input-usd-per-million` and `--output-usd-per-million`, positive `--post-call-threshold-usd`, and positive `--max-input-tokens` and `--max-output-tokens`. Before POST, the encoded request must fit within the declared input token ceiling in bytes, and the cost modeled from both token ceilings and prices must fit the threshold. For example, add `--model jev-1.13.0 --price-source typesafe-public-model-page --price-date 2026-09-21 --input-usd-per-million 0.042 --output-usd-per-million 0 --max-input-tokens 1000 --max-output-tokens 100 --post-call-threshold-usd 0.01`. These are caller-declared ceilings, not TypeSafe-enforced limits. Provider-added tokens or output beyond the declaration can still incur a larger charge. Do not label this a provider hard cap.

Actual usage and modeled cost become known after the call. `budget_exceeded` means the already-incurred modeled cost exceeded the configured threshold. A responding model that differs from the pinned ID, missing usage, or usage above the declared ceilings produces unknown cost and a deterministic `keep` fallback; observed usage remains available. Timeout, invalid choice, or low confidence also fall back to `keep`. All receipts keep `applied_action=keep`: shadow mode never alters a user request. Direct callers of `shadow_decide` must persist and account for its receipt; the `Julius` SDK method performs that ledger write. A provider-enforced limit or a provable upper bound plus atomic reservation and reconciliation is still needed before claiming a hard spending cap.

Confidence is a threshold on a reported value, not a calibrated success probability. The [frozen synthetic shadow pilot](jev-shadow-evaluation.md) can check five optional cases against a pinned model without changing production actions. Before enabling active decisions, measure cost and quality on target tasks and add an explicit non-shadow policy gate.
