# Explicit Claude print session

`run_claude_print(prompt=..., project_id=..., data_dir=..., max_turns=..., max_budget_usd=..., timeout_seconds=...)` launches one explicit Claude Code print session. It passes the prompt on stdin, uses temporary Julius settings and recovery MCP JSON, and supplies `--print --output-format stream-json --verbose --no-session-persistence` plus turn and USD budget limits. Julius removes the temporary configuration and does not write the raw prompt to its own files. Claude Code owns authentication, network requests, and its own runtime behavior; the caller must authorize this external session.

The parser reads only the final `result.usage` counters and `result.total_cost_usd`, reporting them as a client-reported **session delta**. It does not sum nested assistant message usage or claim per-call measurement. A single observed model is reported as `actual_model`; absent or multiple observed models leave that field null. Missing, malformed, negative, and boolean counters remain null. Nonzero exit, missing final result, client error, malformed stream, and timeout are incomplete. Session totals may include multiple turns, tools, and subagents; they do not prove savings from a specific Julius transformation.

The implementation follows Claude Code's documented [`--print`, `--output-format stream-json`, `--no-session-persistence`, `--max-turns`, and `--max-budget-usd` flags](https://code.claude.com/docs/en/cli-reference). Offline fixtures validate parsing and command construction; they do not establish live client compatibility or a measured model result.
