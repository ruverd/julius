# Explicit Claude print session

`run_claude_print(prompt=..., project_id=..., data_dir=..., max_turns=..., max_budget_usd=..., timeout_seconds=..., model=...)` launches one explicit Claude Code print session. It passes the prompt on stdin, uses temporary Julius settings and recovery MCP JSON, and supplies `--print --output-format stream-json --verbose --no-session-persistence` plus turn and USD budget limits. It also uses restricted mode, disables built-in tools, and denies unattended permission prompts. Julius removes the temporary configuration and does not write the raw prompt to its own files. Claude Code owns authentication, network requests, and its own runtime behavior; the caller must authorize this external session.

The parser reads only the final `result.usage` counters and `result.total_cost_usd`, reporting them as a client-reported **session delta**. It returns the final answer to the explicit caller but does not store it in the ledger. It does not sum nested assistant message usage or claim per-call measurement. A single observed model is reported as `actual_model`; absent or multiple observed models leave that field null. Missing, malformed, negative, and boolean counters remain null. Nonzero exit, missing final result, client error, malformed stream, and timeout are incomplete. Session totals may include multiple turns, tools, and subagents; they do not prove savings from a specific Julius transformation. The CLI normalizes Claude's cache fields into an input total and records a dated client estimate if model identity is known; it does not call that estimate a provider charge or subscription refund.

The implementation follows Claude Code's documented [`--print`, `--output-format stream-json`, `--no-session-persistence`, `--max-turns`, and `--max-budget-usd` flags](https://code.claude.com/docs/en/cli-reference). Offline fixtures validate parsing and command construction. One [live synthetic call](live-claude-validation.md) completed on Claude Code 2.1.278; broader compatibility and task quality remain unverified.
